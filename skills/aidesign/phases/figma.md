# Figma — проект для глаз, только по согласию

Читается **только после «да» человека**: на Передаче, когда в сайте 4 и больше страниц и он согласился на предложение (`phases/6-handoff.md` §7), или в любой момент, когда он сам попросил «покажи в Figma», «обнови Figma». Отказался — этот файл не открывается, и о Figma в этом прогоне больше ни слова.

**Код остаётся главным.** Figma — витрина, чтобы увидеть весь сайт разом и показать его другим. Скажи это человеку одной строкой до начала: «В Figma будут картинки страниц — без анимации, наведения и других эффектов, они живут только на сайте. Поправить что-то — скажи мне, я поправлю код и обновлю Figma». Правки, сделанные в Figma руками, на сайт сами не переходят.

Работает с Figma только **ведущий агент**: он подключает Figma MCP и вызывает его инструменты. Скиллы Figma хоста (`figma-use`, `figma-generate-design`, `figma-generate-library`), если они есть, загружает тоже только ведущий агент; субагентам Figma не поручается.

## 1. Подключена ли Figma

Посмотри в списке своих инструментов: есть инструменты Figma MCP (`whoami`, `generate_figma_design`, `use_figma`, `create_new_file`) — подключена, переходи к разделу 3. Нет — раздел 2.

## 2. Подключить

Сервер Figma MCP — удалённый, адрес `https://mcp.figma.com/mcp`; вход — через Figma в браузере, человек делает его сам, пароль в чат не просится. Команды под среду печатает `python3 .aidesign-work/setup.py plan figma --host claude` (или `--host codex`):

| Среда | Подключение |
|---|---|
| Claude Code | `claude mcp add --transport http figma https://mcp.figma.com/mcp` — или плагин `figma@claude-plugins-official` (`claude plugin install figma@claude-plugins-official`); затем в сессии `/mcp` → figma → войти в браузере |
| Codex | `codex mcp add figma --url https://mcp.figma.com/mcp`, затем `codex mcp login figma` — откроется браузер для входа |

- Команда меняет настройки агента — перед ней `ad.py ask action --note "подключить Figma"` и вопрос «Подключаю Figma (а) или пропускаем (б)?». После «а» выполни команду сам; вход в браузере — человек.
- Новые инструменты появляются **после перезапуска сессии**. Скажи одной строкой: «Подключил. Перезапусти меня и напиши «продолжи AI Design» — продолжу с Figma». Прогон не закрывай: `finish` ещё не было, продолжение поднимет его (`phases/0-start.md` §10).
- Не вышло — код и последние строки вывода человеку, развилка «повторить (а), пропустить (б)». Пропустили — прогон сдаётся без Figma.

## 3. Какой путь: бесплатный или платный

Перенос страниц в Figma (Code to canvas, инструмент `generate_figma_design`) доступен на всех тарифах, включая бесплатный. Построение файла (`use_figma`: свои страницы, фреймы, переменные) — только на платном плане Figma и с правом редактировать файл. Узнай одним вопросом, если не видно из `whoami`: «У тебя платная Figma и ты можешь редактировать этот файл (а) или бесплатная (б)? Не знаешь — (б)». Платное скилл не покупает и не включает; бесплатный путь — всегда запасной.

## 4. Бесплатный путь — все страницы кадрами

1. Подними локальный сервер сайта (`knowledge/инструменты.md`, раздел 1) и составь список страниц по порядку разделов: главная, затем `pages/…` в порядке меню.
2. Новый файл Figma — `create_new_file` (или файл, который назвал человек), название «<проект> — сайт».
3. Каждую страницу перенеси инструментом `generate_figma_design` дважды — на ширине **1280** и **390**, по инструкции, которую вернёт инструмент (и по скиллу `figma-generate-design`, если он загружен). Раскладка — **на одной странице файла**: верхний ряд — 1280, нижний — 390, слева направо по порядку разделов; над каждым кадром подпись с адресом страницы (`/`, `/pages/about.html`).
4. Ссылку на файл — `python3 .aidesign-work/ad.py figma set --url <ссылка> --mode free`; затем строка в `DESIGN.md`, в блоке `aidesign` и в отчёте.
5. **Обновление** («обнови Figma»): новые кадры ставятся рядом, правее старых, с датой в подписи; удалить старые бесплатный путь сам не может — скажи человеку одной строкой, какие кадры старые и что их можно удалить руками. Снова `ad.py figma set` — время обновления на панели.

## 5. Платный путь — файл разложен по разделам

Перед первым `use_figma` загрузи скилл `figma-use`, если хост его даёт: Figma требует этого. Файл раскладывается так:

| Страница файла | Что на ней |
|---|---|
| Обложка | название проекта, направление одной строкой, дата, ссылка на сайт, если он опубликован |
| по странице на раздел сайта | кадры 1280 и 390 этого раздела рядом, подпись с адресом |
| Карта сайта | уменьшенные кадры всех страниц и стрелки переходов по внутренним ссылкам меню и кнопок |
| Дизайн-система | цвета, шрифты, отступы и радиусы из `design-system/tokens.json` — переменными Figma и образцами с подписями; не из головы и не со снимков |

- Кадры страниц переносятся тем же `generate_figma_design`, раскладку, страницы, стрелки и переменные строит `use_figma` (по скиллу `figma-generate-library` для дизайн-системы, если он есть).
- **Обновление**: старые кадры заменяются новыми на тех же местах, переменные дизайн-системы — по свежему `tokens.json` (`designsystem.py export` перед этим).
- `python3 .aidesign-work/ad.py figma set --url <ссылка> --mode paid`, строки в `DESIGN.md`, блоке `aidesign`, отчёте.

## 6. Ограничения бесплатного тарифа — сказать и соблюдать

- **Чтение из Figma ограничено** — на бесплатном тарифе порядка 20 вызовов чтения в месяц (`get_design_context`, `get_screenshot`, `get_metadata`). Поэтому Figma **не читается без нужды**: всё, что нужно знать о дизайне, — в коде и `design-system/`, а не в Figma. Запись (`generate_figma_design`, `create_new_file`) этот лимит не тратит.
- Лимит кончился или инструмент отказал — одна строка человеку, что не так, и прогон сдаётся без Figma; ничего платного взамен не включается.

Человеку одной строкой при первом подключении на бесплатном тарифе: «Бесплатная Figma разрешает мне мало читать из неё, поэтому я только кладу туда страницы, а правлю сайт по коду».

## Не делать

- Предлагать Figma второй раз после «нет» или на маленьком сайте без его слова.
- Поручать Figma субагенту или загружать скиллы Figma из субагента.
- Покупать, включать пробный период или менять тариф; просить пароль от Figma.
- Переносить в сайт правки, сделанные в Figma, без слов человека — он скажет, что поменять.
- Читать Figma «чтобы проверить», когда то же видно в коде.
