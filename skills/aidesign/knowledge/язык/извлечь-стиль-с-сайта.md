# Извлечь стиль с сайта

## Когда читать

- Этап «Референсы»: человек дал ссылку на сайт, который ему нравится.
- Вход «готовый сайт»: нужно снять текущий стиль своего сайта перед редизайном.
- Человек хочет «как у Stripe/Linear/…» — есть готовые разборы брендов.

## Три случая — три пути

| Случай | Путь |
|---|---|
| Чужой сайт-референс | разобрать **признаки** (цвет, шрифт, раскладка, настроение) и перенести идею, не копию |
| Свой готовый сайт | снять токены точно и записать в `DESIGN.md` как исходное состояние |
| «Как у известного бренда» | готовый разбор бренда (getdesign.md) как референс стиля |

## Путь 1. Без установки: агент смотрит сам

Работает всегда, ничего не ставит.

1. Если доступен браузер агента — открыть сайт на 1280 и 390, сделать снимки, прочитать вычисленные стили ключевых элементов: `body`, `h1`–`h3`, кнопка, ссылка, карточка, поле.
2. Если браузера нет — попросить у человека скриншоты первого экрана и одного внутреннего раздела. Pinterest и сайты за входом агент сам не откроет — попросить скачать картинки в папку `референсы/`.
3. Записать в `refs.md` по каждому референсу: палитра (4–6 hex с ролями), шрифты (класс гарнитуры, если имя не видно), шкала и вес, раскладка (сетка, плотность, ритм), форма (радиусы, тени), движение (если видно), настроение одной фразой, **что именно человеку понравилось** (спросить).

## Путь 2. Точные токены: dembrandt

Открытый инструмент (MIT): открывает сайт в безголовом браузере, обходит DOM, читает вычисленные стили и выдаёт систему: цвета с уверенностью, стили текста, шкалу отступов, радиусы, тени, состояния компонентов.

```bash
npx dembrandt install-browser            # один раз: скачать браузер (~сотни МБ)
npx dembrandt https://example.com --design-md      # сразу DESIGN.md
npx dembrandt https://example.com --dtcg --save-output   # токены W3C DTCG
npx dembrandt https://example.com --mobile         # телефонная ширина
npx dembrandt https://example.com --dark-mode      # тёмная тема
npx dembrandt https://example.com --crawl 5        # несколько страниц
npx dembrandt https://example.com --wcag           # контраст на реальных парах
```

- Нужен Node 18+. Ставить только с согласия человека (это скачивание браузера); бесплатно.
- `--compare baseline.json` — ловит «уплывание» токенов своего сайта после правок.
- `--tokens <файл>` — проверяет отрисованные цвета, радиусы и размеры против своих токенов.

## Путь 3. Свой готовый сайт по коду

Если код сайта в проекте (вход «готовый сайт»), токены снимаются из исходников (Imp, extract):

- Найти, где живут цвета, шрифты, отступы: CSS-переменные, `tailwind.config`, тема, повторяющиеся значения.
- Токеном становится то, что повторяется 3+ раза с одним смыслом; разовое — не токен.
- Два похожих элемента с разным назначением — остаются разными.
- Записать в `DESIGN.md` как «текущее состояние» до редизайна — это база для превью «как станет».

## Путь 4. Готовые разборы брендов

getdesign.md и awesome-design-md содержат DESIGN.md, снятые с публичных сайтов известных компаний (`npx getdesign@latest add <slug>`, нужен Node 18+). Правила:

- Это **референс стиля**, а не айдентика человека: брать язык (плотность, ритм, тип шкалы), а не логотип, фирменные цвета и шрифты бренда целиком.
- Часть стилей getdesign платная (Catalog Pass) — не брать без разрешения человека; распространять их нельзя.
- В публичный репозиторий скилла файлы брендов не копируются.

## Этика: что можно, что нельзя

- Можно: изучать, измерять, переносить **принципы** (dembrandt-skills: «воспроизведение страницы — это исследование»).
- Нельзя: выдавать чужую раскладку, тексты, фото и бренд за свои; копировать фирменный эффект сайта целиком (Taste: «не копировать код, тексты, картинки и фирменный эффект референса»).
- Уважать `robots.txt` и условия сайта; не обходить вход и защиту.
- Если человек хочет «точно как этот сайт» — объяснить разницу и предложить превью «в духе» с его содержанием.

## Если делаем копию своего сайта (перенос, редизайн)

По dembrandt-skills `clone-website`:

- Снимать отрисованное состояние, а не HTML с сервера: на клиентских сайтах только оно содержит всё.
- Текст и картинки брать из захвата, не перепечатывать.
- Сравнивать три вещи: вид, структуру, **смысл** (слова, ссылки, цифры) — третью чаще всего теряют.
- Сравнить токены оригинала и новой версии — разница и есть список оставшейся работы.
- Шрифт без лицензии для автоматической среды — сначала совместимый по метрикам запасной, потом замена.

## Не делать

- Ставить инструменты без согласия человека.
- Открывать сайты за входом с чужими cookie.
- Переносить фото и тексты с чужого сайта в превью человека.
