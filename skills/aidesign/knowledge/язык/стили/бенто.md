# Бенто-сетка

**Одной строкой:** плитки разного размера в одной сетке, как отделения коробки бенто.

## Когда читать

Страница продукта с несколькими возможностями, портфолио, личный сайт, сводка; человек показывает референс «как у Apple», «плитками».

## Признаки

- Сетка с разными пролётами плиток (`grid-column: span 2`), ровные промежутки 12–16px.
- Каждая плитка — **одна мысль**, у главной — больше места.
- Нейтральная база, акцент у интерактивных плиток.
- Внутри плиток — живые фрагменты: кусок интерфейса, фото, схема, цифра из брифа.

## Когда уместно и когда нет

- **Да:** сводка возможностей, где пункты **неравны** по весу; личные сайты.
- **Нет:** длинный текст, таблицы данных, формы, мониторинг.

## Почему работает

Разный размер плиток сам показывает иерархию. Шаблоном бенто становится, когда плитки одинаковые, а внутри — «иконка → заголовок → строка» (`антипаттерны.md#card-grid`).

## Токены-ориентиры

- Сетка: 4–6 колонок, `grid-auto-rows` 180–240px, промежуток 12–16px.
- Форма: радиус 16–24px, **одна** система подъёма: тень или граница (`антипаттерны.md#ghost-card`).
- Движение: подъём плитки на 2px при наведении, 150–200ms.

## Сочетания

- **Хорошо:** швейцарский, игривый яркий, необрутализм, тёмный «дорогой» (плитки-поверхности).
- **Осторожно:** стекло (одна плитка), видео в плитке (одно, без звука).
- **Плохо:** редакционный, бумажный, экстремальный минимализм.

## Не делать

- Все плитки одного размера — это просто сетка карточек.
- Иконка в скруглённом квадрате над заголовком в каждой плитке.
- Каталог предлагает масштаб 1.02 у плитки при наведении — допустимо только для ссылочных плиток; плитка не должна сама уезжать из-под курсора (Imp: двигается вложенный слой, а не сама плитка).

## Запасной вариант

На телефоне — одна колонка в порядке важности; главная плитка первой. При reduced-motion — без подъёма, смена тона.
