# Стили: карта семейств

## Когда читать

- После интервью (или разбора референсов), чтобы выбрать **ведущую стилистику** и две соседние для трёх превью.
- Когда человек назвал стиль словом («брутализм», «как у Apple») — найти его семейство здесь.

## Как выбирать

1. **Сначала поверхность и режим посетителя** (Imp): пришёл убедиться и впечатлиться (лендинг, портфолио) — стиль может владеть страницей; пришёл работать или читать (приложение, документация) — стиль даёт только шрифт, палитру, плотность и один фирменный приём, а раскладку и элементы управления оставляет стандартными.
2. **Потом предмет и тип дела** (Taste): кафе, магазин, услуга — фото и типографика ведут, без шейдеров и сцен; софт, игры, железо — допустим один эффект.
3. **Потом вкус человека** из `vkus.md`: слова, которые он сказал, и «что точно не про нас».
4. **Одна ведущая стилистика на проект.** Приёмы из других семейств — только из колонки «сочетается» и по правилу `../сочетание.md`.
5. **Три превью — три разных семейства или три разные трактовки одного**, если человек уже точно назвал стиль. Различие — композиция, шрифт, ритм, а не только цвет (`../../движение-и-медиа/превью.md`).

Каталог UI UX Pro Max подбирает стиль по правилам отрасли, Taste — случайной раздачей по типу дела; у нас решает бриф и интервью, а отраслевые подсказки — только стартовая гипотеза (`../решения-споров.md`, спор 7).

## Перевод слов человека в семейства

| Человек говорит | Смотреть |
|---|---|
| «чисто», «строго», «ничего лишнего» | швейцарский, экстремальный минимализм |
| «дорого», «премиум», «как в кино» | тёмный «дорогой», экстремальный минимализм |
| «как журнал», «умно», «чтобы читали» | редакционный, бумажный |
| «дерзко», «смело», «не как у всех» | брутализм, необрутализм, кинетическая типографика |
| «весело», «ярко», «для молодых» | игривый яркий, необрутализм |
| «уютно», «тепло», «натурально» | природный, ремесленный, мягкий объём |
| «технологично», «как у Apple» | инженерный, бенто, стекло (одна панель) |
| «как фильм», «история» | сюжетный, тёмный «дорогой» |
| «ностальгия», «80-е», «нулевые» | ретро-футуризм, ремесленный-аналоговый |

## Не делать

- Брать «дефолтные» значения из каталогов стилей, которые совпадают с антипаттернами (фиолетовый неон у стекла, пружина у клея, Inter у швейцарского, градиентный текст у кинетики) — в каждом файле стиля это отмечено.
- Смешивать два ведущих семейства на одной странице.
- Называть стиль человеку жаргоном без картинки: показывать превью.
