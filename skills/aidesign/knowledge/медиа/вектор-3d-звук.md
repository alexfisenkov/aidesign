# Вектор, иконки, 3D и звук

## Когда читать

- Нужны иконки особого рисунка, иллюстрации в векторе, логотип-набросок.
- На странице будет 3D-предмет (товар, который крутят мышью) или 3D-сцена.
- Человек попросил звук (редко: на сайте звук почти всегда лишний).

Простые иконки, градиенты, шум и частицы — сначала [кодом-вместо-генерации.md](кодом-вместо-генерации.md): бесплатно и легче. Допуск WebGL и бюджет видеокарты — [../движение-и-медиа/webgl-и-3d.md](../движение-и-медиа/webgl-и-3d.md).

## Вектор и иконки

1. **Сначала готовый открытый набор**, если рисунок обычный (часы, адрес, телефон): Lucide, Phosphor, Tabler — целиком один набор, лицензия в отчёт. Почему: иконки одного рисунка из набора согласованы лучше, чем сгенерированные по одной.
2. **Генерация вектора — когда нужен свой рисунок** (иллюстрации раздела, иконки ремесла, которых нет в наборах). Recraft отдаёт SVG моделями с окончанием `_vector` (Recraft V4.1, V4, V3, V2; V2 — под иконки и минималистичный вектор), остальные модели — растр (сверено 19.11.2026 по [обзору моделей Recraft](https://www.recraft.ai/docs/api-reference/models/overview)). Через агрегаторы (Higgsfield, fal, Replicate) Recraft тоже доступен — поля и цена у каждого свои.
3. **Промпт иконки:** предмет + «line icon, single stroke weight, rounded caps, no fill, 24×24 grid, centered, no text, no background». Для набора — одна фраза стиля во всех промптах и один референс-образец уже утверждённой иконки. Почему: без общей фразы каждая иконка рисуется своей толщиной.
4. **После генерации SVG:**
   - открыть и посмотреть глазами в размере 16, 24 и 48 px;
   - сжать: `npx svgo icon.svg -o icon.min.svg` (только с согласия на установку пакета; без него — убрать вручную лишние группы и метаданные);
   - у иконок — `viewBox="0 0 24 24"`, цвет заменить на `currentColor`, фиксированные `width`/`height` убрать — размер задаёт CSS;
   - собрать в один `<symbol>`-набор, как в рецепте 6.
5. **Растр в вектор** (есть только картинка логотипа) — векторизация (у Recraft отдельная операция) даёт черновик: проверь узлы и кривые; логотип бренда перерисовывает дизайнер или берётся у владельца бренда, а не «вытягивается» из картинки.

## 3D: предмет в GLB для сайта

Формат для сайта — **GLB** (один файл: сетка, материалы, текстуры). three.js читает его `GLTFLoader`, а `<model-viewer>` показывает вовсе без кода.

**Откуда взять:**

| Путь | Когда | Что известно (сверено 19.11.2026) |
|---|---|---|
| Своя модель у человека | есть файл от производителя или дизайнера | конвертировать в GLB (Blender: экспорт glTF Binary) |
| Meshy | 3D из текста или фото | задача асинхронная: создаётся, потом опрашивается до готовности; сначала «превью» — геометрия без текстур, затем «доработка» — текстуры, в том числе PBR; форматы задаются списком (`glb`). Модели устаревают по расписанию — перед запуском смотри страницу устаревания в [документации Meshy](https://docs.meshy.ai/api/text-to-3d) |
| Magnific | 3D из картинки в веб-интерфейсе | 3D Generator: выбор модели, скачивание GLB; за кредиты ([страница инструмента](https://www.magnific.com/ai/docs/3d-generator); страница при сверке не открылась, данные по выдаче поиска) |
| Higgsfield | 3D из картинки через подключённый MCP | в инструкциях сервера Higgsfield MCP на 19.11.2026 назван инструмент `generate_3d`; формат файла и цену проверь по ответу сервера до запуска — непроверено |
| Кодом | абстрактная форма, частицы, «жидкий» объект | three.js-примитивы или шейдер ([кодом-вместо-генерации.md](кодом-вместо-генерации.md)) — бесплатно |

**Промпт 3D-предмета:** один предмет, без окружения и пола; «game-ready / web-ready, clean topology, realistic PBR materials»; материалы словами (матовая глазурь, шлифованная латунь); для «из фото» — фото предмета на ровном фоне, 2–4 ракурса, если сервис принимает несколько.

**Подготовить под сайт:**
- вес — ориентир до 2–5 МБ; сжать: `npx @gltf-transform/cli optimize in.glb out.glb --texture-compress webp` (с согласия на пакет) — сжатие сетки и текстур в WebP; сжатую сетку three.js читает только с декодером (`GLTFLoader.setMeshoptDecoder` или `DRACOLoader` — смотря чем сжато, `--compress draco|meshopt`), `<model-viewer>` подключает декодеры сам;
- проверить масштаб и центр (предмет стоит в начале координат, «вверх» — ось Y);
- постер-картинка того же ракурса — обязательна: видна до загрузки, при reduced-motion и без WebGL;
- кручение — по перетаскиванию, не по колесу (колесо не перехватываем);
- `<model-viewer src="mug.glb" poster="mug.webp" alt="Кружка, синяя глазурь" camera-controls>` — самый короткий путь, если нужен только «покрутить предмет».

**Правда:** сгенерированная 3D-модель товара — приближение; для магазина она должна совпасть с настоящим товаром по форме и цвету, иначе — только как иллюстрация с подписью.

## Звук

На сайте звук почти всегда лишний: автозапуск со звуком браузеры блокируют, а посетитель закрывает вкладку. Уместен только: короткий звук по действию человека (редко), фоновая атмосфера в «погружающем» проекте — **выключена по умолчанию**, включается кнопкой с названием («Включить звук», `aria-pressed`), громкость тихая, при уходе со вкладки — пауза.

- **ElevenLabs Sound Effects** (сверено 19.11.2026 по [документации](https://elevenlabs.io/docs/overview/capabilities/sound-effects)): модель `eleven_text_to_sound_v3` — новая, `eleven_text_to_sound_v2` — по умолчанию, но устаревает (удаление 01.03.2027); длительность до 30 с; есть режим бесшовной петли (для атмосферы: дождь, гул зала); MP3 для всего, WAV 48 кГц — только не для петель.
- **Промпт звука:** действие, место, атмосфера, а не категория — «soft rain on a tin roof of a small workshop, distant thunder, calm». Для последовательности — порядок событий. Музыке можно задать темп и тональность («90 BPM, F minor»). Точное число повторов («ударь 4 раза») модель соблюдает не всегда.
- **Подготовить:** нормализовать громкость, обрезать тишину, MP3 или AAC около 96–128 кбит/с; петлю проверить на стыке 3–4 круга подряд.
- Звук на видео первого экрана — нет: видео фона беззвучное ([промпты-видео.md](промпты-видео.md)).

## Не делать

- Генерировать иконки по одной без общей фразы стиля и образца.
- Вставлять SVG с фиксированным цветом и размером там, где нужен `currentColor`.
- «Вытягивать» логотип бренда из картинки и выдавать за настоящий.
- GLB на 30 МБ без сжатия и без постера.
- Крутить 3D колесом мыши или запускать WebGL без запасного кадра.
- Автозапуск звука и звук без видимой кнопки выключения.
