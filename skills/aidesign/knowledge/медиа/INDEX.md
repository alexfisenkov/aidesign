# Медиа для сайта: что читать

## Когда читать

- Интервью, тема «Медиа»: человек ответил, откуда медиа (свои, генерация, вперемешку, кодом, плашки) и что нужно.
- Превью: главный приём варианта требует материала (видео, фото, частицы).
- Сборка: план медиа `media-plan.md` по местам страницы.

Этот файл — маршрут: по ответу человека и месту на странице он называет, что открыть. Всё сразу не читай.

## По источнику (ответ интервью)

| Источник | Что делает скилл | Читать |
|---|---|---|
| **свои** | просит папку или файлы, проверяет размер и качество, готовит под сайт; генерирует только недостающее и только с «да» | [../движение-и-медиа/фото.md](../движение-и-медиа/фото.md), [../движение-и-медиа/видео.md](../движение-и-медиа/видео.md), [качество-фото.md](качество-фото.md) (раздел «Своё фото человека») |

## Порядок работы на Сборке

1. Подключённые генераторы и бюджет — [генераторы.md](генераторы.md).
2. План медиа `media-plan.md`: место → источник → сервис и модель → промпт → размер → что прочитано.
3. Генерация ведущим агентом по общему циклу, проверка каждого результата глазами, не больше двух перегенераций одного места без вопроса.
4. Подготовка (`media.py prep`), опись `assets/media.json` (`media.py record`), итог — в отчёт.

## Не делать

- Читать всю папку перед каждой картинкой.
- Генерировать то, что делается кодом или есть у человека своё.
- Начинать платную генерацию без бюджета ([генераторы.md](генераторы.md)).
