# Кодом вместо генерации: частицы, шейдер, градиент, шум, иконки

## Когда читать

- Источник медиа «кодом»: человеку нужна графика без фото (частицы, живой фон, мягкий градиент, зерно, иконки).
- Генератора нет или бюджет не названы, а первый экран не должен быть пустым.
- Превью: приём «частицы» или «шейдер» показывается настоящим кодом с первого круга, а не картинкой-намёком.
- Перед каждой генерацией фона или текстуры: сначала спроси себя, не делается ли это кодом бесплатно и легче.

Про допуск WebGL, бюджет видеокарты и цену на телефоне — [../движение-и-медиа/webgl-и-3d.md](../движение-и-медиа/webgl-и-3d.md); здесь только готовые рецепты.

## Правила

1. **Кодом — всё, что не должно выглядеть как фотография.** Частицы, туман из точек, градиент, зерно, бумажная фактура, иконки, линии. Почему: такая графика весит килобайты, не платная, правится словами («теплее», «реже») и не рассыпается на большом экране.
2. **Каждый рецепт — один файл без библиотек.** Почему: превью и сайт открываются и по `file://`, и с любого сервера; нечему не загрузиться.
3. **Цвета — из палитры направления.** В рецептах стоят нейтральные тёплые тона; перед вставкой замени их на токены (`design-system/tokens.css`). Фиолетово-синий градиент и кислотный неон на чёрном не берутся (`../язык/антипаттерны.md`).
4. **Движение — медленное и выключаемое.** Каждый движущийся рецепт: при `prefers-reduced-motion: reduce` рисует один неподвижный кадр; вне экрана и на скрытой вкладке не считает; плотность пикселей не выше 2. Почему: фон за текстом не должен отнимать внимание и батарею.
5. **Текст поверх — читаемый.** Контраст проверяй по самому светлому месту фона; если не хватает — затемни фон, а не обводи буквы.
6. **Один громкий приём на экран** (`../язык/сочетание.md`). Частицы и шейдер одновременно — уже два.
7. **Проверка.** После вставки: `python3 .aidesign-work/check.py <файл>` без находок и снимок в браузере: канвас рисует, движение есть, а с reduced-motion — стоит.

Как выбрать:

| Нужно | Рецепт | Цена |
|---|---|---|
| Живой фон с «воздухом», пыль в луче, снег | 1. Частицы canvas | лёгкий, до ~200 точек |
| Много точек (тысячи), глубина | 2. Частицы WebGL | один контекст WebGL |
| Плывущий фон, свет, «жидкость» | 3. Шейдер-фон | один контекст WebGL, считается в половине разрешения |
| Мягкий цветной фон без пятен-клякс | 4. Mesh-градиент | почти бесплатно |
| Зерно, бумага, «плёнка» поверх фото и градиента | 5. SVG-шум | один фон, без движения |
| Иконки одного рисунка | 6. SVG-иконки | ноль запросов |

## 1. Частицы на canvas

Тёплая пыль, медленно поднимается. Количество точек — от площади экрана, не больше 160.

```html
<!doctype html>
<html lang="ru">
<head>
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>Частицы на canvas</title>
<style>
  body { margin: 0; }
  .hero { position: relative; min-height: 70svh; display: grid; align-items: end; padding: 8vw 6vw; background: #201c18; color: #f3ede4; overflow: hidden; }
  .hero canvas { position: absolute; inset: 0; width: 100%; height: 100%; }
  .hero h1 { position: relative; margin: 0; font: 600 clamp(2rem, 5vw, 4rem)/1.1 Georgia, serif; }
</style>
</head>
<body>
<section class="hero">
  <canvas aria-hidden="true"></canvas>
  <h1>Мастерская у реки</h1>
</section>
<script>
(() => {
  const canvas = document.querySelector('.hero canvas');
  const ctx = canvas.getContext('2d');
  const still = matchMedia('(prefers-reduced-motion: reduce)');
  const color = '#f3ede4';
  let dots = [], w = 0, h = 0, raf = 0, last = 0, onScreen = true;

  function resize() {
    const dpr = Math.min(window.devicePixelRatio || 1, 2);
    w = canvas.clientWidth; h = canvas.clientHeight;
    canvas.width = Math.round(w * dpr); canvas.height = Math.round(h * dpr);
    ctx.setTransform(dpr, 0, 0, dpr, 0, 0);
    const count = Math.round(Math.min(160, (w * h) / 9000));
    dots = Array.from({ length: count }, () => ({
      x: Math.random() * w, y: Math.random() * h, r: 0.6 + Math.random() * 1.8,
      vx: (Math.random() - 0.5) * 6, vy: -4 - Math.random() * 12, a: 0.2 + Math.random() * 0.5
    }));
    draw();
  }
  function draw() {
    ctx.clearRect(0, 0, w, h);
    ctx.fillStyle = color;
    for (const d of dots) {
      ctx.globalAlpha = d.a;
      ctx.beginPath(); ctx.arc(d.x, d.y, d.r, 0, Math.PI * 2); ctx.fill();
    }
    ctx.globalAlpha = 1;
  }
  function step(now) {
    const dt = Math.min((now - (last || now)) / 1000, 0.05); last = now;
    for (const d of dots) {
      d.x += d.vx * dt; d.y += d.vy * dt;
      if (d.y < -4) { d.y = h + 4; d.x = Math.random() * w; }
      if (d.x < -4) d.x = w + 4; else if (d.x > w + 4) d.x = -4;
    }
    draw();
    raf = requestAnimationFrame(step);
  }
  function sync() {
    cancelAnimationFrame(raf); raf = 0; last = 0;
    if (onScreen && !still.matches && !document.hidden) raf = requestAnimationFrame(step);
  }
  new ResizeObserver(resize).observe(canvas);
  new IntersectionObserver(([e]) => { onScreen = e.isIntersecting; sync(); }).observe(canvas);
  still.addEventListener('change', sync);
  document.addEventListener('visibilitychange', sync);
})();
</script>
</body>
</html>
```

Настройки на словах: «реже» — делитель площади 9000 → 14000; «медленнее» — скорости `vy` вдвое меньше; «снег» — `vy` положительная, точки крупнее; «пыль в луче» — точки только в полосе, остальные с `a` около 0,05.

## 2. Частицы на WebGL

Тысячи точек считает видеокарта: положение каждой — из её номера и времени, процессор ничего не двигает. Нет WebGL — остаётся тёмный фон блока.

```html
<!doctype html>
<html lang="ru">
<head>
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>Частицы на WebGL</title>
<style>
  body { margin: 0; }
  .field { position: relative; min-height: 70svh; display: grid; align-items: end; padding: 8vw 6vw; background: #16191b; color: #eef1ee; overflow: hidden; }
  .field canvas { position: absolute; inset: 0; width: 100%; height: 100%; }
  .field h1 { position: relative; margin: 0; font: 600 clamp(2rem, 5vw, 4rem)/1.1 Georgia, serif; }
</style>
</head>
<body>
<section class="field">
  <canvas aria-hidden="true"></canvas>
  <h1>Ночная обсерватория</h1>
</section>
<script>
(() => {
  const canvas = document.querySelector('.field canvas');
  const gl = canvas.getContext('webgl', { antialias: false, premultipliedAlpha: true });
  if (!gl) return;
  const still = matchMedia('(prefers-reduced-motion: reduce)');
  const COUNT = 3000;
  const vs = `
    attribute vec4 seed;
    uniform float t; uniform vec2 size; uniform float dpr;
    varying float alpha;
    void main() {
      float y = fract(seed.y + t * seed.z * 0.02);
      float x = seed.x + sin(t * 0.3 + seed.w * 6.28) * 0.01;
      gl_Position = vec4(x * 2.0 - 1.0, y * 2.0 - 1.0, 0.0, 1.0);
      gl_PointSize = (1.0 + seed.w * 2.5) * dpr;
      alpha = 0.15 + seed.w * 0.6;
    }`;
  const fs = `
    precision mediump float;
    varying float alpha;
    void main() {
      float d = length(gl_PointCoord - 0.5);
      gl_FragColor = vec4(vec3(0.93, 0.95, 0.93) * alpha, alpha) * smoothstep(0.5, 0.2, d);
    }`;
  function shader(type, src) {
    const s = gl.createShader(type); gl.shaderSource(s, src); gl.compileShader(s); return s;
  }
  const prog = gl.createProgram();
  gl.attachShader(prog, shader(gl.VERTEX_SHADER, vs));
  gl.attachShader(prog, shader(gl.FRAGMENT_SHADER, fs));
  gl.linkProgram(prog);
  if (!gl.getProgramParameter(prog, gl.LINK_STATUS)) return;
  gl.useProgram(prog);
  const data = new Float32Array(COUNT * 4);
  for (let i = 0; i < data.length; i++) data[i] = Math.random();
  gl.bindBuffer(gl.ARRAY_BUFFER, gl.createBuffer());
  gl.bufferData(gl.ARRAY_BUFFER, data, gl.STATIC_DRAW);
  const loc = gl.getAttribLocation(prog, 'seed');
  gl.enableVertexAttribArray(loc);
  gl.vertexAttribPointer(loc, 4, gl.FLOAT, false, 0, 0);
  const uT = gl.getUniformLocation(prog, 't');
  const uDpr = gl.getUniformLocation(prog, 'dpr');
  gl.enable(gl.BLEND); gl.blendFunc(gl.ONE, gl.ONE_MINUS_SRC_ALPHA);
  let raf = 0, onScreen = true, lost = false;

  function draw(seconds) {
    gl.viewport(0, 0, canvas.width, canvas.height);
    gl.clearColor(0, 0, 0, 0); gl.clear(gl.COLOR_BUFFER_BIT);
    gl.uniform1f(uT, seconds);
    gl.drawArrays(gl.POINTS, 0, COUNT);
  }
  function resize() {
    const dpr = Math.min(window.devicePixelRatio || 1, 2);
    canvas.width = Math.round(canvas.clientWidth * dpr);
    canvas.height = Math.round(canvas.clientHeight * dpr);
    gl.uniform1f(uDpr, dpr);
    draw(performance.now() / 1000);
  }
  function loop(now) { draw(now / 1000); raf = requestAnimationFrame(loop); }
  function sync() {
    cancelAnimationFrame(raf); raf = 0;
    if (!lost && onScreen && !still.matches && !document.hidden) raf = requestAnimationFrame(loop);
  }
  canvas.addEventListener('webglcontextlost', (e) => { e.preventDefault(); lost = true; sync(); });
  new ResizeObserver(resize).observe(canvas);
  new IntersectionObserver(([e]) => { onScreen = e.isIntersecting; sync(); }).observe(canvas);
  still.addEventListener('change', sync);
  document.addEventListener('visibilitychange', sync);
})();
</script>
</body>
</html>
```

`COUNT` больше 5000 на телефоне не ставь. Глубина: крупные точки (`seed.w` ближе к 1) ярче и быстрее — уже заложено.

## 3. Шейдер-фон

Плывущие тёплые тени, как свет через листву. Считается в половине разрешения — для размытого фона разницы не видно, а видеокарте вчетверо легче. Пока шейдер не нарисовал первый кадр и если WebGL нет, виден градиент в CSS — это постер.

```html
<!doctype html>
<html lang="ru">
<head>
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>Шейдер-фон</title>
<style>
  body { margin: 0; }
  .glow { position: relative; min-height: 70svh; display: grid; align-items: end; padding: 8vw 6vw; color: #fbf7ef; overflow: hidden;
          background: linear-gradient(160deg, #6b4f3a, #2f3b33); }
  .glow canvas { position: absolute; inset: 0; width: 100%; height: 100%; }
  .glow h1 { position: relative; margin: 0; font: 600 clamp(2rem, 5vw, 4rem)/1.1 Georgia, serif; }
</style>
</head>
<body>
<section class="glow">
  <canvas aria-hidden="true"></canvas>
  <h1>Чайная в саду</h1>
</section>
<script>
(() => {
  const canvas = document.querySelector('.glow canvas');
  const gl = canvas.getContext('webgl', { antialias: false });
  if (!gl) return;
  const still = matchMedia('(prefers-reduced-motion: reduce)');
  const vs = 'attribute vec2 p; void main() { gl_Position = vec4(p, 0.0, 1.0); }';
  const fs = `
    precision mediump float;
    uniform vec2 res; uniform float t;
    float hash(vec2 p) { return fract(sin(dot(p, vec2(127.1, 311.7))) * 43758.5453); }
    float noise(vec2 p) {
      vec2 i = floor(p), f = fract(p); vec2 u = f * f * (3.0 - 2.0 * f);
      return mix(mix(hash(i), hash(i + vec2(1, 0)), u.x), mix(hash(i + vec2(0, 1)), hash(i + vec2(1, 1)), u.x), u.y);
    }
    float fbm(vec2 p) { float v = 0.0, a = 0.5; for (int i = 0; i < 5; i++) { v += a * noise(p); p *= 2.0; a *= 0.5; } return v; }
    void main() {
      vec2 uv = gl_FragCoord.xy / res; uv.x *= res.x / res.y;
      float n = fbm(uv * 2.2 + vec2(t * 0.03, -t * 0.02) + fbm(uv * 1.4 - t * 0.015));
      vec3 deep = vec3(0.18, 0.23, 0.20), warm = vec3(0.42, 0.31, 0.23), light = vec3(0.86, 0.72, 0.52);
      vec3 col = mix(deep, warm, smoothstep(0.25, 0.6, n));
      col = mix(col, light, smoothstep(0.62, 0.85, n) * 0.6);
      gl_FragColor = vec4(col, 1.0);
    }`;
  function shader(type, src) { const s = gl.createShader(type); gl.shaderSource(s, src); gl.compileShader(s); return s; }
  const prog = gl.createProgram();
  gl.attachShader(prog, shader(gl.VERTEX_SHADER, vs));
  gl.attachShader(prog, shader(gl.FRAGMENT_SHADER, fs));
  gl.linkProgram(prog);
  if (!gl.getProgramParameter(prog, gl.LINK_STATUS)) return;
  gl.useProgram(prog);
  gl.bindBuffer(gl.ARRAY_BUFFER, gl.createBuffer());
  gl.bufferData(gl.ARRAY_BUFFER, new Float32Array([-1, -1, 3, -1, -1, 3]), gl.STATIC_DRAW);
  const loc = gl.getAttribLocation(prog, 'p');
  gl.enableVertexAttribArray(loc);
  gl.vertexAttribPointer(loc, 2, gl.FLOAT, false, 0, 0);
  const uRes = gl.getUniformLocation(prog, 'res');
  const uT = gl.getUniformLocation(prog, 't');
  const SCALE = 0.5;
  let raf = 0, onScreen = true, lost = false;

  function draw(seconds) {
    gl.viewport(0, 0, canvas.width, canvas.height);
    gl.uniform2f(uRes, canvas.width, canvas.height);
    gl.uniform1f(uT, seconds);
    gl.drawArrays(gl.TRIANGLES, 0, 3);
  }
  function resize() {
    canvas.width = Math.max(1, Math.round(canvas.clientWidth * SCALE));
    canvas.height = Math.max(1, Math.round(canvas.clientHeight * SCALE));
    draw(performance.now() / 1000);
  }
  function loop(now) { draw(now / 1000); raf = requestAnimationFrame(loop); }
  function sync() {
    cancelAnimationFrame(raf); raf = 0;
    if (!lost && onScreen && !still.matches && !document.hidden) raf = requestAnimationFrame(loop);
  }
  canvas.addEventListener('webglcontextlost', (e) => { e.preventDefault(); lost = true; sync(); });
  new ResizeObserver(resize).observe(canvas);
  new IntersectionObserver(([e]) => { onScreen = e.isIntersecting; sync(); }).observe(canvas);
  still.addEventListener('change', sync);
  document.addEventListener('visibilitychange', sync);
})();
</script>
</body>
</html>
```

Цвета — три `vec3` (доли от 0 до 1: `#2f3b33` → `0.18, 0.23, 0.20`). Скорость — множители при `t`. Медленнее 0,01 движение уже не видно; быстрее 0,08 фон начинает отвлекать от текста.

## 4. Mesh-градиент

Мягкий фон из нескольких цветовых точек, которые плавно перетекают. Не размытые пятна-кляксы на пустом фоне (это примета шаблона), а сплошное поле цвета, как на фотофоне. Канвас крошечный (48 на 27 точек), браузер растягивает его сам и сглаживает. По умолчанию неподвижен; лёгкий дрейф включается только без reduced-motion.

```html
<!doctype html>
<html lang="ru">
<head>
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>Mesh-градиент</title>
<style>
  body { margin: 0; }
  .mesh { position: relative; min-height: 70svh; display: grid; align-items: end; padding: 8vw 6vw; background: #d9cbb4; color: #2a241d; overflow: hidden; }
  .mesh canvas { position: absolute; inset: 0; width: 100%; height: 100%; }
  .mesh h1 { position: relative; margin: 0; font: 600 clamp(2rem, 5vw, 4rem)/1.1 Georgia, serif; }
</style>
</head>
<body>
<section class="mesh">
  <canvas width="48" height="27" aria-hidden="true"></canvas>
  <h1>Пекарня на углу</h1>
</section>
<script>
(() => {
  const canvas = document.querySelector('.mesh canvas');
  const ctx = canvas.getContext('2d');
  const W = canvas.width, H = canvas.height;
  const still = matchMedia('(prefers-reduced-motion: reduce)');
  const points = [
    { x: 0.10, y: 0.15, c: [236, 222, 199] }, { x: 0.85, y: 0.10, c: [214, 190, 160] },
    { x: 0.55, y: 0.55, c: [226, 205, 178] }, { x: 0.15, y: 0.90, c: [196, 176, 150] },
    { x: 0.90, y: 0.85, c: [241, 231, 214] }, { x: 0.45, y: 0.05, c: [205, 186, 168] }
  ];
  const img = ctx.createImageData(W, H);
  let raf = 0, onScreen = true;

  function paint(seconds) {
    const live = points.map((p, i) => ({
      x: p.x + Math.sin(seconds * 0.05 + i * 1.7) * 0.06,
      y: p.y + Math.cos(seconds * 0.04 + i * 2.3) * 0.06, c: p.c
    }));
    for (let y = 0; y < H; y++) {
      for (let x = 0; x < W; x++) {
        let r = 0, g = 0, b = 0, sum = 0;
        for (const p of live) {
          const dx = x / (W - 1) - p.x, dy = (y / (H - 1) - p.y) * 0.6;
          const k = Math.exp(-(dx * dx + dy * dy) / 0.06);
          r += p.c[0] * k; g += p.c[1] * k; b += p.c[2] * k; sum += k;
        }
        const i = (y * W + x) * 4;
        img.data[i] = r / sum; img.data[i + 1] = g / sum; img.data[i + 2] = b / sum; img.data[i + 3] = 255;
      }
    }
    ctx.putImageData(img, 0, 0);
  }
  function loop(now) { paint(now / 1000); raf = requestAnimationFrame(loop); }
  function sync() {
    cancelAnimationFrame(raf); raf = 0;
    if (onScreen && !still.matches && !document.hidden) raf = requestAnimationFrame(loop);
  }
  paint(0);
  new IntersectionObserver(([e]) => { onScreen = e.isIntersecting; sync(); }).observe(canvas);
  still.addEventListener('change', sync);
  document.addEventListener('visibilitychange', sync);
})();
</script>
</body>
</html>
```

Цвета точек — близкие по светлоте оттенки одной палитры; разница светлоты больше 15 % даёт «пятна». Полосы на плавном переходе (бандинг) снимает зерно из рецепта 5 поверх.

## 5. SVG-шум: зерно и бумага

Фактура без файла картинки: фильтр `feTurbulence` внутри SVG прямо в CSS. Кладётся поверх фото, градиента или однотонного фона слоем без событий мыши.

`baseFrequency` 0,6–0,9 — мелкое зерно, 0,01–0,1 — пятна и волокна (два числа — разная частота по горизонтали и вертикали). Сила — `opacity` слоя: зерно заметно при 0,15–0,4; сильнее — грязь. ## Не делать

- Брать фото-генерацию для того, что рисуется кодом за минуту: фон-градиент, зерно, иконки.
- Подключать библиотеку частиц или 3D ради одного эффекта, если рецепт выше справляется.
- Двигать фон без reduced-motion и считать его на скрытой вкладке или вне экрана.
- Ставить два живых фона на один экран или живой фон под длинный текст.
- Анимировать зерно и шум.
- Размытые цветные пятна на пустом фоне вместо сплошного градиента (`../язык/антипаттерны.md`, «пятна»).
- Иконки-эмодзи и иконки из разных наборов на одной странице.
