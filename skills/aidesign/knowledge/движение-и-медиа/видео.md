# Видео на сайте: героическое и фоновое

## Когда читать

- У человека есть ролик, и он хочет его на сайте: фон первого экрана, демонстрация продукта, атмосфера.
- Направление «кинематографично», «живой первый экран».
- Видео должно двигаться от прокрутки или стать основой сайта — сразу `видео-в-сайт.md`, базовые правила отсюда.

## Три роли видео

| Роль | Что это | Звук | Управление |
|---|---|---|---|
| **Фоновое** | короткий бесшумный цикл за заголовком, атмосфера | нет звуковой дорожки вообще | кнопка паузы, больше ничего |
| **Героическое** | главный кадр первого экрана: продукт в работе, место, процесс; может быть циклом или клипом 6–20 с | нет при автозапуске | пауза; «смотреть полностью» открывает версию со звуком |
| **Содержательное** | ролик, который смотрят: обзор, интервью, урок | есть | стандартные элементы управления, субтитры, без автозапуска |

## Когда уместно

- **Уместно**: место с движением (кухня, мастерская, природа), продукт в работе, мода, музыка, события, кинематографичное направление.
- **Неуместно**: фоновое видео «для красоты» за текстом сервиса, кабинета, документации. Абстрактные стоковые «частицы» и «город в таймлапсе» — клише.
- **Предмет раньше эффекта**: видео показывает то, что продаётся, а не настроение вместо него.
- Не больше одного автозапускаемого видео в экране.

## Разметка фонового и героического видео

```html
<video class="hero-video" autoplay muted loop playsinline preload="metadata"
       poster="/media/hero-poster.avif" aria-hidden="true">
  <source src="/media/hero-1280-av1.mp4" type='video/mp4; codecs="av01.0.05M.08"'>
  <source src="/media/hero-1280.mp4" type="video/mp4">
</video>
<button class="video-toggle" aria-label="Остановить видео">…</button>
```

- **`muted` + `playsinline` + `autoplay`** — без этого не запустится: автозапуск без звука браузеры разрешают, со звуком — нет; на iPhone без `playsinline` видео рвётся в полноэкранный режим.
- **Постер обязателен**: первый кадр (или самый выразительный) в AVIF/WebP. Его видно до загрузки, при reduced-motion, при экономии трафика и если автозапуск не сработал (на iPhone в режиме энергосбережения автозапуск может не случиться).
- **Порядок `<source>`**: сначала современный кодек, последним — H.264 MP4, который играет везде. Браузер берёт первый, который умеет.
- **Декоративное видео** — `aria-hidden="true"`, без `controls`; текст первого экрана — живой HTML поверх, не вшит в видео.
- **Кнопка паузы** видна всегда, доступна с клавиатуры. Требование WCAG 2.2.2: всё, что движется само дольше 5 секунд рядом с другим содержимым, можно остановить.
- **Контраст текста над видео** проверяй по самому светлому и самому тёмному кадру цикла; если не держится — плашка или затемнение конкретной зоны под текстом.

## Кодеки

| Кодек | Где играет | Зачем |
|---|---|---|
| H.264 (MP4) | везде | обязательный запасной |
| AV1 (MP4 или WebM) | Chrome, Edge, Firefox; Safari — на устройствах с аппаратным декодером | на 30–50 % легче H.264 при том же качестве |
| VP9 (WebM) | Chrome, Edge, Firefox; Safari частично | альтернатива AV1 |
| HEVC (MP4) | Safari, часть остальных при аппаратной поддержке | только если нужен альфа-канал на Apple |

Поддержка меняется — перед выпуском сверяйся с MDN и caniuse. Правило простое: один современный + H.264.

## Кодирование (ffmpeg)

Общие правила: без звуковой дорожки (`-an`) для фонового и героического; `+faststart` (заголовок файла в начале — видео начинает играть, не скачавшись целиком); `yuv420p` для совместимости; один набор настроек на все ролики сайта.

```bash
# H.264, компьютер, 1280 px, 30 кадров/с
ffmpeg -i исходник.mov -an -vf "scale=1280:-2,fps=30" -c:v libx264 -preset slow -crf 26 \
  -pix_fmt yuv420p -movflags +faststart hero-1280.mp4

# AV1 (если ffmpeg собран с libsvtav1)
ffmpeg -i исходник.mov -an -vf "scale=1280:-2,fps=30" -c:v libsvtav1 -crf 38 -preset 6 \
  -pix_fmt yuv420p -movflags +faststart hero-1280-av1.mp4

# Телефон: вертикальный кадр 9:16 из центра, 720 px
ffmpeg -i исходник.mov -an -vf "crop=ih*9/16:ih,scale=720:-2,fps=30" -c:v libx264 -preset slow \
  -crf 27 -pix_fmt yuv420p -movflags +faststart hero-720-portrait.mp4

# Постер из первого кадра
ffmpeg -ss 0 -i hero-1280.mp4 -frames:v 1 -q:v 2 hero-poster.jpg
```

Вертикальная версия из центра — запасной путь: если предмет не в центре, нужен отдельный монтаж под телефон. Цикл должен замыкаться: последний кадр похож на первый, или в конце — 0,3–0,5 с кроссфейда.

## Вес

| Что | Ориентир |
|---|---|
| Фоновый цикл 6–12 с, телефон 720p | 0,5–1,5 МБ |
| Фоновый цикл 6–12 с, компьютер 1080p | 1,5–4 МБ |
| Героический клип до 20 с | до ~6 МБ на компьютере, до ~2,5 МБ на телефоне |
| Частота кадров | 24–30; 60 — только если движение быстрое и это видно |

Если не укладывается: короче цикл, меньше разрешение, выше `crf`, спокойнее картинка (шум, листва и вода сжимаются хуже всего).

## Отдельные файлы для телефона и компьютера

`<source media>` у видео поддерживается не везде, поэтому надёжнее выбирать файл скриптом при загрузке (`matchMedia('(max-width: 640px)')`, `(pointer: coarse)`) или серверной разметкой. Телефону — вертикальный 720p, компьютеру — горизонтальный 1080p или 1280.

## Загрузка

- Фоновое на первом экране: `preload="metadata"`, постер виден сразу; само видео — после первой отрисовки страницы.
- Видео ниже первого экрана: `preload="none"`, источник подставляется, когда секция подходит к экрану (`IntersectionObserver`), и видео ставится на паузу, когда ушло.
- Вкладка в фоне — пауза (`visibilitychange`).
- Экономия трафика (`navigator.connection?.saveData`, где поддерживается) — только постер.
- Встраивание YouTube/Vimeo — «фасад»: картинка-превью и кнопка, сам `iframe` (через `youtube-nocookie.com`) — по нажатию. Тяжёлый плеер не грузится, пока его не попросили.

## Reduced-motion

При `prefers-reduced-motion: reduce` фоновое и героическое видео не запускаются сами: виден постер, кнопка «воспроизвести» доступна. Проверяй в CSS и в JS (не вызывать `play()`).

## Содержательное видео

- Никакого автозапуска со звуком.
- Субтитры (`<track kind="captions" srclang="ru">`, WebVTT) для речи — требование WCAG 1.2.2; для длинных роликов — расшифровка текстом рядом.
- Пропорция контейнера задана (`aspect-ratio: 16/9`), чтобы не было сдвига раскладки.

## Сделать видео, если его нет

- Из фото: медленный наезд или панорама по одному фото (ffmpeg `zoompan`) — честный короткий цикл без генерации.
- Из HTML-анимации: инструменты «HTML → MP4» (например, HyperFrames, открытый, Apache-2.0) — когда нужен ролик для первого экрана из своей графики.
- Генерация видео нейросетью — платная: только с прямого разрешения человека и с названной суммой, сначала короткий пробный ролик; права и модель фиксируются в отчёте.

## Не делать

- Звук при автозапуске.
- Видео без постера (чёрный прямоугольник при загрузке и на iPhone в энергосбережении).
- Текст, вшитый в видео.
- Видео весом в десятки мегабайт на первом экране.
- Фоновое видео за длинным текстом.
- Два автовидео в одном экране; видео + WebGL-сцена + свой курсор на одном первом экране.
